📐 gradebook

Two tools that grade a repository against a weighted rubric and tell you which fix buys the most points.

gradebook-tests scores the test suite; gradebook-code scores the code it covers. They are independent programs in sibling folders — install one, both, or neither. Neither needs config, a build, or a test run: each is a read-only pass over the working tree plus git log, across Python, JS/TS, Go, Java/Kotlin, Ruby, PHP, Rust, C#, Elixir, Scala and more.

Install
pipx install ./gradebook-tests
pipx install ./gradebook-code

then: gradebook-tests . and gradebook-code .
